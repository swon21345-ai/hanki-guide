# 한 끼 가이드 — 전국 대학생 맛집 별점 가이드

대학 이메일(.ac.kr)로 인증한 학생이 식당을 등록하고, 5가지 기준으로 채점하면
평균으로 별이 붙는 웹사이트입니다. 링크만 있으면 누구나 볼 수 있고, 대학생은 로그인해서 입력합니다.

## 파일 구성

| 파일 | 하는 일 | 주로 고칠 사람 |
|---|---|---|
| `index.html` | 페이지 뼈대 (홈·맛집 찾기·식당 상세·등록·별 기준·소개·내 정보) | 화면 담당 |
| `css/style.css` | 디자인 (라이트/다크 모드) | 디자인 담당 |
| `js/config.js` | **Firebase 설정값**, 별 기준 인원(`minRaters`), 가성비 가격 기준 | 배포 담당 |
| `js/data.js` | 지역·카테고리 목록, 처음 넣을 포항 식당 14곳 | 데이터 담당 |
| `js/store.js` | 로그인·저장 (Firebase / 데모 모드) | 배포 담당 |
| `js/app.js` | 화면 동작, 채점 항목(`CRITERIA`), 소개 페이지 조원(`TEAM`) | 기능 담당 |
| `firestore.rules` | 데이터베이스 보안 규칙 | 배포 담당 |

## 지금 바로 보기 (데모 모드)

`index.html`을 브라우저로 열면 됩니다. `config.js`에 Firebase 값을 넣기 전에는 **데모 모드**로 동작해요.
- 학교 이메일 형식(`아무거나@학교.ac.kr`)만 넣으면 메일 없이 바로 로그인돼요.
- 입력한 내용은 그 브라우저에만 저장돼요. 다른 사람에게는 안 보여요.
- 로그아웃 후 다른 이메일로 들어가면 여러 학생처럼 채점해 볼 수 있어요 (5명이 채점하면 별이 붙음).
- 화면 위 "데모 초기화"를 누르면 처음 상태로 돌아가요.

## 실제로 배포하기 (무료)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. 프로젝트 홈에서 **웹 앱 추가(</>)** → 앱 이름 입력 → 나오는 `firebaseConfig` 값 중
   `apiKey`, `authDomain`, `projectId`, `appId`를 `js/config.js`의 `FIREBASE_CONFIG`에 붙여 넣기

### 2. 학교 이메일 로그인 켜기
1. **Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호**
2. "이메일/비밀번호"와 **"이메일 링크(비밀번호가 없는 로그인)"를 모두 사용 설정** → 저장
3. **Authentication → 설정 → 승인된 도메인**에 배포할 주소를 추가
   (예: `우리아이디.github.io`). 로컬 테스트용 `localhost`는 기본으로 들어 있어요.

### 3. 데이터베이스 만들기
1. **Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
2. **규칙** 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**

### 4. 사이트 올리기 (GitHub Pages)
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 전부 올리기 (`index.html`이 맨 위에 있어야 함)
2. 저장소 **Settings → Pages → Branch: main / (root) → Save**
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생겨요. 이 주소가 학생들에게 나눠 줄 링크예요.
4. 이 도메인(`아이디.github.io`)을 2-3단계의 승인된 도메인에 넣었는지 다시 확인하세요.

### 5. 운영진 지정과 첫 데이터
1. 사이트에서 운영진이 학교 이메일로 한 번 로그인
2. Firebase 콘솔 **Authentication → 사용자**에서 그 사람의 **사용자 UID** 복사
3. **Firestore → 컬렉션 시작 → 컬렉션 ID `admins` → 문서 ID에 UID 붙여 넣기** → 필드 아무거나(예: `name` = 이름) → 저장
4. 사이트 **내 정보** 화면에 "운영진 도구"가 보이면 **포항 예시 식당 불러오기**를 한 번 누르기
5. 운영진은 모든 식당 페이지에서 식당·채점을 지울 수 있어요 (광고·장난 글 정리용).

## 알아 둘 점
- **.ac.kr 이외 주소를 쓰는 학교**가 있으면 `config.js`의 `allowedEmail`과 `firestore.rules`의 `matches(...)` 두 곳을 함께 고쳐야 해요.
- 무료 요금제(Spark)는 하루 로그인 메일 발송량과 데이터 읽기 횟수에 한도가 있어요. 학생이 아주 많아지면 콘솔의 사용량 탭을 확인하세요.
- 식당을 지워도 그 식당의 채점 문서는 남아요(화면에는 안 보임). 필요하면 콘솔에서 정리하세요.
- 로그인 메일이 스팸함으로 갈 수 있어요. 학생들에게 미리 알려 주세요.
- 이메일 주소는 화면에 공개되지 않고, 채점에는 닉네임과 학교 이름만 보여요.
